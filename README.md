# Vishal Tripathy — Engineering Portfolio

Production-grade engineering portfolio built with Next.js, React, TypeScript and Vercel.

## Product

The portfolio is designed as an engineering product rather than a conventional resume site.

It emphasizes:

- Flagship engineering projects
- Architecture and system design evidence
- Production engineering decisions
- Engineering Exploration
- Technical documentation
- Recruiter-friendly storytelling
- Accessibility, performance and security

The goal is simple:

> Show how I think, build and ship production-grade AI software systems.

## Engineering Architecture

- Next.js / React / TypeScript
- Server-first rendering
- Structured TypeScript content
- Data-driven project architecture
- Dynamic project routes
- SEO metadata and structured data
- Dynamic sitemap and robots configuration
- Production security headers
- Contact API with validation and abuse protections
- CSS-based motion with reduced-motion support
- Responsive and accessible UI
- Vercel deployment
- No database required for the current portfolio
