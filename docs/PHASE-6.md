## Visual integrity rule

The portfolio does not invent screenshots, benchmark numbers, infrastructure metrics or deployment evidence.

Where an authentic screenshot/diagram exists, it can be added through the existing media model. Until then, technical visuals are generated from the documented architecture and explicitly presented as system maps.
